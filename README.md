# SNS Automation

A personal social media content management tool.

## About SNS Automation

SNS Automation is a tool designed to help its operator prepare, manage, and upload social media content to authorized accounts.

## Features

- Social media content preparation
- AI-assisted content creation
- Image and video content management
- Authorized account integration
- Video draft uploads
- Manual review before final publication

## TikTok Integration

SNS Automation is intended to use official TikTok APIs to authenticate authorized accounts and upload video content as drafts. Final publication is performed by the account holder.
